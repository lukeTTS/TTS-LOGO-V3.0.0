# Version 3.0.0 – customer interface preview

Official supplied logo and brand mark, branded application icon, side-by-side previews, live destination and output summary, connection test, help, and verification guidance. Existing graphic encoders and upload payloads retained. Unmatched Windows queues require manual selection. GoDEX network connection test does not send Zebra identification commands. Update button hidden.

## Validation before distribution
- Build via existing Windows GitHub Actions workflow with version 3.0.0.
- Open at 100%, 125%, 150% Windows scaling; check scrolling and keyboard access.
- Verify all four profiles, clean launch defaults, crop/rotation/threshold and exports.
- Check missing printer, missing image, invalid port, failed preview and connection failure.
- Upload to each supported physical printer and print a tag from its tester.
- Complete signing and the remaining reliability/security review before public release.

Static XML and handler/name checks only were performed in the editing environment; no Windows build or physical printer test was possible.
