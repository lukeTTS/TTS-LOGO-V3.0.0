# Seaward PCX and editable filename update

- Added **Seaward tester with Zebra ZQ printer** as an equipment preset.
- Seaward preset defaults to `PASS.PCX`.
- Restored an editable printer filename field for all printer/tester combinations.
- Added a visible Zebra file-format selector: **Zebra GRF** or **Seaward PCX**.
- Zebra PCX uploads now accept valid custom names, not only `PASS.PCX` and `FAIL.PCX`.
- File extensions are applied automatically; users enter only the base filename.
- GoDEX output remains `.bmp` and Zebra Alpha output remains `.GRF` by default.
- The selected filename and Zebra file format are saved in application settings.
