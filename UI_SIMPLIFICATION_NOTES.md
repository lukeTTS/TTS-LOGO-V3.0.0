# Simplified Equipment Workflow

The main interface now starts with one equipment setup selector:

1. Metrel Alpha 3340 with GoDEX printer
2. Metrel Alpha 3340 with Zebra ZQ521 printer
3. Metrel 3309BT with GoDEX printer

The selected setup automatically configures the printer type, output filename and canvas behavior.

- Alpha 3340 + GoDEX: `custlogo.bmp`, 360 x 360 canvas enabled.
- Alpha 3340 + Zebra ZQ521: `custlogo.GRF`, Zebra flash storage enabled.
- Metrel 3309BT + GoDEX: `custlogo.bmp`, no separate 360 x 360 canvas by default.

Technical file export, command details, diagnostics, crop coordinates and canvas controls remain available in collapsed advanced sections.

The legacy TLP2824 Plus workflow is not shown or added.
